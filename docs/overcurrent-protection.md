# 2S 供电的过流保护（方案说明，未完成选型）

初稿日期：2026-10-10；主保险必要性复核：2026-10-12。适用于当前 NP-F550 2S / HAT / HD-1910 候选架构；**没有选定保险丝安数，没有实物接线、短路或堵转测试，也没有验证当前电池的 BMS。**结论以[必要性复核](./references/power-review-20261010/research.md#2026-10-12-主保险是否必要)为准：先查电池内置保护，暂不预购外置保险。

依据：[供电架构](./power-architecture-v2.md)、[接线验证单](./hat-v1.2-test.md)、[供电复核与器件证据](./references/power-review-20261010/research.md)。本页的保护方法是工程设计建议，不是厂家针对本机给出的认证接法。

## 先确认问题是否存在

本页解释可用的保护方法，不表示已证明本机堵转会烧 HAT，也不要求先买新配电板。最新[堵转风险核查](./references/stall-hat-risk-20261010/research.md)确认：C001 规格书的过流卸载出厂默认关闭，所述动作是超阈值持续一定时间再关输出，非瞬时保护；用户实物配置未知。按 V1.0 图，舵机大电流不经过主控 5V/2A 降压输出，需评估直通接头/铜箔的电流—时间耐受。**先只读回查实际保护配置与图物路径，再决定保护/配电如何调整。**

## 1. 只有在电池自身保护不足或不明时，才考虑外置主保险

```
电池 → banana_pcb 取电
          正极 + ──（必要时外置保险 F）── 断电连接件/开关 ──→ 已核准的电源入口 +BATT
          负极 − ─────────────────────────────────────────→ GND
```

- 独立保险并非所有带 BMS 电池系统都必需。若电池资料能确认其输出端具有合适的短路/过流切断，并足以保护外部取电线束，可不另加；当前到货电池的品牌、准确型号和保护规格未登记，故**目前只列为待核，不购买保险丝与保险座，也不能因此直接使用电池带整机**。
- 若电池没有该保护，或资料无法确认保护能力，再考虑外置保险。保险应串在正极线上，不是横跨正负极，也不是接 DATA；尽量靠近电池出线，缩短并固定/绝缘保险前未保护导线。
- 不需要为了确认或增加保护而拆开电池包或焊电芯。取电触点/banana_pcb 自身仍要做好绝缘、固定，并核实其上游能否及时切断故障电流。
- 使用带绝缘外壳、与导线/保险匹配的保险座；线材、压接端子和保险座额定必须满足实际负载、温度和故障保护要求。
- 如采用外置保险，总开关置于保险之后；若由电池内置保护承担过流切断，则按最终正极保护拓扑布置断电连接件。开关按明确的**直流电压和负载通断电流**选择，不能只看交流标称。开关只供手动切断，不会自动检测过流；普通拨动开关也不等于合格的急停系统。
- 保险主要用于切断短路或持续过载，保护线束/配电，**不保证故障时芯片一定不损坏**，也不负责稳压、欠压保护或充电。

## 2. 不能现在直接定“5A 保险”

当前 EH 座按项目参考额定约 3A，而社区整机常态参考 3–5A，尚无本机峰值/持续时间数据；A 入口拟承担全机电流。**载流能力不足必须先改配电，不能靠保险把 3A 接头变成 5A 接头。**

保险上的 3A/5A 并不是刚超过该电流就瞬间断开。动作时间取决于过流倍数、温度和具体曲线；即使标称 3A 的保险也不一定能充分保护一个 3A 接头。

选型要同时满足：

1. 正常连续负载、启动和运动峰值在考虑温度降额后，不会引发不必要熔断。
2. 故障时保险动作时间与允许通过的能量（I²t）不超过被保护导线、端子和器件的耐受能力。
3. **直流额定电压**覆盖母线最大电压（2S 满电 8.4V）及设计规定的瞬态条件；有明确直流额定的 32V 插片保险是候选类别之一，不是已选定型号。
4. **直流分断能力**覆盖电池可能提供的短路电流；没有电池/BMS 资料时不能假定一定满足。保险座也必须相容。
5. 选择快断还是延时型要依动作曲线与浪涌/受保护路径协调，不能因“电机启动大”就默认慢断，或因“安全”就默认快断。

如果正常工作范围与被保护路径的安全范围不重叠，就**不存在仅靠换保险安数解决的办法**。这时应升级入口、线束、配电或调整负载设计。

## 3. 对当前整机的建议

### 台架阶段

先按 HAT 验证单使用有限流的直流电源，逐板/单舵机验证。在已确认的线材与接头额定内设置合适限流，遇持续顶限或电压塌陷停止排查，不盲目加大电流。

台架电源的限流只在连接台架电源时有效；换成电池后不会自动保留这层保护。电源输出电容也可能提供瞬时故障电流，台架限流不是“接错也不会坏”的保证。

### 整机阶段

电池输出的短路/过流保护必须有明确依据，但可以由电池内置保护承担；**是否需要外置主保险取决于该保护能否覆盖外部取电线束**。此项未核实前，不以电池给整机供电；台架阶段使用按测试单设置的限流电源。另需有可安全断电的连接/操作方式，但不把手动开关当过流保护。**在一个 EH 入口载流问题解决前，不按现有单链图接全机带载。**

若核实实际电流确实超过 HAT 入口能力，评估“电池 → 主保护 → 额定足够的配电点 → 舵机动力支路 + HAT 逻辑支路”。细支路在分支处设置匹配保护；主保险未必保护得了每根更细的支路线。

这只是下一步配电设计方向，不是已验证的施工图。若舵机在 HAT 外部取电，必须重新设计三线总线的供电连接，避免原有 +BATT 线绕过支路保险/开关或并成意外电流路径；DATA 需要可靠的共同地参考，也不能把细信号地线变为主要电机回流通路。

## 4. 是否需要电子过流保护板

可选，不是“独立稳压板”的同义词。

| 方式 | 能做什么 | 限制 |
|---|---|---|
| 一次性保险丝 | 被动切断短路/过载；结构简单 | 熔断后要排查原因再换同规格；不是精确瞬时限流 |
| PTC 自恢复保险 | 受热后增阻、冷却后恢复 | 动作/保持电流受温度影响，可能较慢并持续有残余电流，不能默认适合整机动力保护 |
| eFuse / 电子断路器 | 可实现限流、故障计时、过载关断 | 需验证输入范围、真实持续电流、热设计/安全工作区、浪涌及反向电流，商品名称不等于合格 |
| 电池 BMS | 若规格合适，可提供短路/过流切断，可能使外置主保险不必要 | 当前电池是否具备、切断阈值/时间及故障电流能力待确认；需判断是否足以保护外部线束和接头，不能只凭“有 BMS”字样认定 |
| 软件扭矩/电流控制 | 减轻正常运行负载、响应部分故障 | 不能保护断线短路、程序失控或未实现的硬件故障，不替代电源保护 |

需要更精细保护时，可评估**限流 + 超时关断、故障后保持断开直到人工复位**的电子保护。单纯长时间恒流可能让主控反复欠压重启，关节也可能持续施力；不要默认周期性自动重试适合机器人。

电机减速可能回灌，保护板还需考虑母线回灌与反向阻断造成的过压；串一个二极管或买一块“5A 保护板”不能自动闭环。外加电容、TVS 或吸收电路也应按能量、电压和故障场景计算，不能随意指定。

断电保护动作后机器人可能失力跌倒，验证时需要安全支撑、人员远离关节，故障安全优先于维持主控不断电。

## 5. 当前采购/验证清单

- [ ] 核实电池标签上的品牌/准确型号与说明书，查明内置保护的短路/过流切断阈值、动作时间和适用电流；与外部线束/接头协调后决定是否省略外置主保险。未知时不以电池给整机供电。
- [ ] 核实动力线长度、线规、压接和回路结构，在允许额定内测正常电流、峰值与持续时间。
- [ ] **仅当电池内置保护不足或无法确认时**，再选有直流数据表的保险丝及配套绝缘保险座，记录额定电压、电流、分断能力、动作曲线和温度降额；**安数待定，不先锁死 5A。**
- [ ] 选择直流额定合适的总开关/断电连接件，固定并绝缘安装；若另有急停需求，单独设计其断电范围与故障状态。
- [ ] 若需要电子保护，获取具体板/芯片资料，验证限流值、关断策略、热设计和回灌行为。
- [ ] 用受控台架与合适负载验证保护及压降，不故意短接电池，不通过卡死整机舵机测保护，不用万用表电流档跨接电池。

结论（2026-10-12）：**现在不先购买独立保险；先确认电池内置保护。内置保护足以覆盖外部线束时可省去外置主保险，缺失或不明时才设计正极近端保险。**“电池短路保护路径是否充分”和“EH 入口本身是否够载”是两个独立问题，前者通过并不代表后者验收通过。


## 其他方案的具体做法

见[EH 与配电比较](./references/power-distribution-comparison-20261010/research.md)：社区 dxl_hub 采用独立两线电源焊盘和部位分支；“不打 HAT”计划让动力正负线单独送各支路、主控另取电并加主保险。这些处理减少小接口承担的总电流，但不等于已验证全机安全，配电与保护仍需分别验收。
