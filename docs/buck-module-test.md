> **2026-10-10 实测完成（空载）**：
>
> | 输入 V | VCC(3P) | PWR OUT(2P) | 判读 |
> |---|---|---|---|
> | 12.0 | 6.00V | 12V | 稳压正常 / 直通 |
> | 7.0 | 6.00V | — | 稳压保持 |
> | 6.6 | 6.00V | 6V | **2S 带载最差点，稳压保持** ✓ |
> | 6.3 | 5.99V | — | 拐点：开始跌落 |

## A 准备（约 2 分钟）

- [ ] A1 万用表：黑笔 COM、红笔 VΩmA，旋钮 V⎓ 60V
- [ ] A2 电源输出关（ON/OFF 灯灭），VOLTAGE 拧到 12.0V
- [ ] A3 设限流 0.3A：红黑夹子互相夹住 → 开输出 → 电源跳 C.C. → 拧 CURRENT 到红屏 0.30A → 关输出、分开夹子
      （空载时红屏读不到限流值，必须靠短路夹子来设；若拧 CURRENT 无反应，试按一下旋钮）

## B 接线（电源保持关闭输出）

- [ ] B1 红夹子夹 XT60 座尾部**+**极焊脚/极耳，黑夹子夹**−**（认板面丝印 +/−；夹子别互碰）
      （有 XT60 公头转接线则插上夹线尾，更好）
- [ ] B2 夹好后拍照核对（极性接反 = 烧板），不确定就发给助手看
- [ ] B3 万用表表笔先不接模块

## C 空载输出测量（判定选压档位）

- [ ] C1 开电源输出。正常：绿屏 12.0V，红屏几十 mA（记下来 = 静耗），C.V. 灯亮
- [ ] C2 表笔测背面 3P 排针焊点：红笔 **VCC**、黑笔 **GND**（别碰到相邻针）→ 记入下表
- [ ] C3 测 2P 接线端子（PWR OUT）两脚 → 记入下表
- [ ] C4 ~~测 DC 母座~~（勘误：板上无此件，系照片误判）
- [ ] C5 判定门：VCC ≈ **5.0V** → 过关继续；读出 6V/7V → **停**，接 IMU 前必须改焊 5V 档（IMU LDO 上限 5.5V）

## 异常速查

| 现象 | 含义 | 动作 |
|---|---|---|
| 开输出电流顶到 0.3A、电压被压低 | 接反或短路 | 立即关输出，查极性 |
| 输出 0V，电流正常小 | 可能欠压锁定或板故障 | 输入升到 7.5V 以上再试 |
| 输出 4.8~4.9V | 5V 档正常容差 | 记录即可 |
| 输出随输入线性变化 | 桥没焊/直通模式 | 查焊盘，改焊后重测 |
