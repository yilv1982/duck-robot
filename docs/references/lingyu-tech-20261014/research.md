## 五、产品体系（官网 + 交付通稿）

官网产品矩阵，从本体到数据一套闭环：

1. **灵御 TA2 双臂机器人**：双 7 轴机械臂、力控反馈、模块化设计；官网展示"零售门店实景作业"。TA 系列（TeleAvatar）2025-09 交付通稿指标：亚毫米级操作精度、端到端操作延迟 <30ms、跨城市全远程操作、双臂及灵巧末端全力控、**起售价 7.99 万元**。
2. **DexUMI 采集设备**：无本体数据采集设备，左右手独立追踪、多模态感知、单只 300g+，支持现场采集与训练准备。
3. **Horus 图传系统**：多模态图传，最低 5Mbps 公网带宽稳定传输，双目高清、H.265、FEC 前向纠错。
4. **灵御数据平台**：覆盖采集、上传、审核、标注与训练准备的数据管理平台。
5. **Nexus 端云协同**："一身多脑"云端协同架构——大脑在云端、本体专注物理执行，低延迟通讯、私有化部署、多专家模型；官网"核心技术能力"页称公网环境端到端延迟 **<90ms**、支持 4G/5G；该方案与**英特尔**合作完成实践验证。

注意："<30ms 端到端操作延迟"（交付稿）与"公网端到端 <90ms"（官网）口径不同，疑似本体侧与公网全链路之别，待核。

### 5.1 产品页补充（2026-10-14 追加，快照 dexteleop-ta2 / dexteleop-dexumi）

**TA2 配置矩阵**：Lite（固定底座，基础训练/标准化数采）→ Standard（全向移动底盘，远程部署/场景试点）→ Pro（全向移动+升降立柱 700–1400mm，广域作业/随行抓取）→ TA2.1 导航版（即将推出：自主移动/自动充电/集群协作）。参数：双臂 7 轴×2、末端负载 5kg、双目帧同步偏差 <100μs、图传 <90ms、运控响应 <30ms、续航 >2h、支持二次开发。官网明确 TA2 "围绕视觉、控制与反馈构建远程操控闭环，操作员在满足网络条件的公网环境下远程控制异地机器人"，但**未写明遥操作端输入设备的形态**（待确认）。

**DexUMI 实为"VR 头显 + UMI 夹爪 + 背包算力"三件套**：基于视觉—惯性融合 UMI 架构（UMI 即斯坦福 Universal Manipulation Interface 手持夹爪采集范式）；VR 头显 680g（头部双目 1920×1920×2、45FPS、Glass-to-Glass <80ms，用于记录第一人称视觉）；UMI 夹爪单只 300g+（腕部双目相机、双指、开口 100mm、最大夹取 1kg，左右手独立追踪）；算力单元 540g（6×Cortex-A78AE + BPU Nash 80TOPS + 12GB LPDDR5，Ubuntu，算力可后置背包）。采集 RGB/深度/IMU/音频并硬件级时间戳对齐，数据用于 TA 模型训练与真机迁移（"TA 同构"）。**注意：DexUMI 官网定位是数据采集设备（人手持真夹爪直接干活记录），不是遥操作主手**；但 VR 头显+腕部相机+手部追踪的硬件组合与遥操作同源。

### 5.2 名词解释：遥操作（teleoperation）与控制器形态（2026-10-14 补充）

- **遥操作 = 人在远处实时操控机器人**：机器人头部相机把视频经网络回传，操作员看着画面（屏幕/VR 头显）实时发控制指令，机器人执行。闭环由"图传下行 + 控制上行"组成，**延迟决定可用性**（灵御口径：公网图传 <90ms、运控响应 <30ms；最低 5Mbps 公网带宽）。
- **不是"完全由人操控"的二元概念**，行业里是一条谱：直接遥操作（人控每个动作）→ 共享控制（机器人管底层稳定/抓握/避障，人下高层指令）→ 监督自主（机器人自主干、卡住才叫人）。灵御明确走混合路线："人机共驾"（L0–L4 全栈），七鲜门店机器人约 80% 自主、复杂情况远程操作员接管；其对家庭终局的判断是"基础家务自主 + 复杂任务众包式遥操作"。
- **行业常见控制器/主手形态**：① 同构主-从臂（leader-follower，主臂与从臂构型一致，如 ALOHA/GELLO，双臂最常用）；② 商用力反馈主手（Force Dimension、Haption、Geomagic，科研经典）；③ VR 头显+手柄/手势（Quest、Vision Pro，Figure 曾演示）；④ 穿戴式手部追踪/动捕手套（Manus 等，灵御 DexUMI 的左右手独立追踪属此思路）；⑤ 游戏手柄/键盘/SpaceMouse（低成本）；⑥ 全身动捕/外骨骼（人形全身遥操作）。
- 灵御 TA2 的遥操作输入设备官网未披露，待确认；从 DexUMI 硬件组合推测其操作范式为"VR 头显看第一视角 + 手部/夹爪类输入"，仅为照片推断级，不作定论。

## 七、战略与技术判断（金戈访谈口径）

- **遥操作三段论**：全自主需要海量真机数据，而规模化真机数据目前只能靠遥操作获取；自动驾驶证明"人在环"长期共存；"自主+遥操作"混合模式是让机器人立刻能工作的唯一方案。遥操作不是备胎，而是"机器人走向世界的方向盘"。
- **落地顺序**：特种/危险作业 → 商业服务与非流水线工业 → 流水线工厂 → **家庭最后攻克**（需求不标准、安全敏感、隐私要求高、无法保证人工干预）。
- **家庭形态判断**：进入家庭时必为"半自主"——基础家务（扫拖收纳等标准化任务）自主完成，复杂长尾任务由专业人员"众包式遥操作"（厨师远程做菜、工程师远程维修、医师远程理疗）。
- **产品哲学**：做减法——轮式+双臂，砍掉与操作无关的结构；"不做展示柜里的艺术品，要做生产线上的蓝领"，"机器人领域的比亚迪：皮实、耐用、算得过账"。
- **底盘策略**：双足/四足/轮式都是"移动底盘"，未来以合作共建推进（AGV、双足四足团队供底盘，灵御供上肢操作系统），模块化组合。

## 九、与本项目（duck-robot）的关系

- **数据采集参照**：灵御 DexUMI（无本体手部数据采集）+ 数据平台 + 遥操作本体的组合，是"真机数据规模化采集"的一种商业化实现；本项目 microduck 路线同样依赖仿真/真机数据做 RL 训练，其"采集-审核-标注-训练准备"流程设计可作参考，但产品不开源，无直接技术依赖。
- **行业观点参照**：其"家庭场景最后攻克、家庭机器人=半自主+远程众包"的判断，与本项目当前"小型陪伴/桌面机器人"定位形成对照——小型低成本四足/鸭子机器人走的是"消费陪伴+简单动作"路线，恰是其认为家庭中最早可自主化的标准化任务之外的非刚需玩法，定位差异值得留意。
- 无供货、采购或技术依赖关系；本报告不改变现行路线、采购与接线计划。
