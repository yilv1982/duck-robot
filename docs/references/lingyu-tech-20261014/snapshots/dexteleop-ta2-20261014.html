灵御 TA2 机器人

面向多场景远程作业的高性能双臂机器人

灵御 TA2 围绕视觉、控制与反馈构建远程操控闭环，支持操作员在满足网络条件的公网环境下远程控制异地机器人。双目视觉与低延迟图传辅助距离判断和动作控制；双臂协同支持抓取、搬运、接触式交互及多步骤作业；全向移动底盘支持机器人在狭窄空间和复杂路径中灵活移动。平台支持算力、软件与功能持续迭代升级，持续拓展机器人在不同场景下的作业能力。
