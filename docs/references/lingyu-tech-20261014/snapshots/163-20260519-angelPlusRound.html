灵御智能完成近亿元天使+轮融资，加速具身智能基础设施布局

上市之家
2026-05-19 20:29 ·北京
0

第一机器人获悉，具身智能AI基础设施企业北京灵御智能科技有限公司近期完成近亿元天使+轮融资。本轮融资由福田资本领投，力合创投、金沙江联合资本、复利多、楹辉创投、华仓资本跟投，老股东英诺基金、天鹰资本持续加注。这是该公司在两个月内斩获的第二笔大额融资，累计融资已达数亿元人民币 。

灵御智能成立于2025年2月，由清华大学自动化系长聘副教授莫一林与前远镜创投管理合伙人金戈联合创立，核心团队汇聚清华、卡内基梅隆等顶尖高校及产业背景，兼具机器人本体研发、运动控制、具身智能算法与量产交付能力。

本轮融资将主要用于灵御TA机器人产品迭代、供应链与交付能力建设，以及高质量真机数据和云端协同系统的持续研发。灵御智能聚焦具身智能产业化核心痛点，构建“灵御TA机器人+高质量真机数据+云端大脑”的核心体系，率先落地“一身多脑”云端协同架构，将机器人“大脑”部署在云端、本体专注物理执行，该方案已与英特尔合作完成实践验证。

商业化方面，灵御智能已实现从技术验证到商业落地的跨越。目前意向订单约3亿元，在手订单约1亿元，2026年预计出货约1000台。灵御TA机器人已在京东七鲜超市等真实场景中完成商品递送、货架取放等多类任务，并在酒店、物流等领域同步推进样机验证。
