## 一、范围与不重叠统计方法

核心对象是面向消费者、以玩乐、情感互动、收藏展示或家庭共玩为主要价值，且电子功能实质参与体验的实体产品。消费级机器人玩具、电子化潮玩和实体 AI 交互玩具属于可能交叉的标签，不是三个可以直接相加的市场。纯软件 AI、工业机器人和主要执行家务的机器人不进入核心分母；非电子潮玩只作消费心理、IP、收藏与渠道的参照。边界产品先登记纳入理由与争议，不因企业自称“机器人”或“AI”自动纳入。

人群主分层为儿童家庭、成人青少年；购买者、使用者和付费决策者分别记录。青少年并不当然等于成人，法律年龄边界交由区域法规证据决定。跨人群产品可贴多个使用标签，但产品实体计数只计一次；无法从销量中拆分人群时，不编造分配比例。

地区以中国、北美、欧洲、日本、韩国为主，东南亚和印度作增量扫描。北美须区分美国、加拿大及资料实际覆盖范围；欧洲须区分欧盟、英国和其他市场，不能把一国结论推广为整个地区。地区缺资料只表示覆盖不足，不表示市场没有需求。

<a id="method-period"></a>
## 二、时间、规模与预测口径

- 对每个重要统计分别记录统计期、发布日期、观察日、地域、币种、价格基础、产品边界、渠道边界和上游原始来源。截止日之后的信息不得混入本轮事实。
- “最新可获完整年”逐来源判断；若只有更早完整年，应保留实际年份，不强行改称最近一年。2026 年季度、半年度、年初至今和已披露全年指引分别列示，不能把部分年份当全年实绩。
- 零售终端金额、厂商收入、出货量、消费者购买量、装机量、活跃设备量和付费账户量分别呈现。不把企业总收入或广义玩具市场作为本研究核心规模。
- 若缺少统一核心口径，优先给可核验的相邻市场边界和不可比原因；只能在覆盖、口径与去重条件满足时构造区间，不强凑一个“全球总额”。多个报告引用同一上游数据，只算一条独立证据链。
- CAGR 仅用于期初期末和口径一致的数据：`g = (V_end / V_start)^(1 / n) - 1`；`n` 为两个统计期端点间的完整年数。计算值标为估计，原始端点均须引用，不以不同报告的端点拼接。
- 2027—2030 年一律进入预测区。区分第三方预测、企业指引和本研究情景，不混称事实。情景写出基期、年增长路径、渗透或保留假设、反证和触发更新条件。无可用基期时只讨论方向和条件，不制造绝对金额。

## 三、证据分类与引用规则

| 标记 | 含义 | 可支持的表达 | 不得升级的结论 |
|---|---|---|---|
| 事实 | 原始记录明确支持的事项，并保留适用范围 | 某监管文本规定、某财报披露、某页面在观察日展示 | 展示价格不等于成交价；某企业情况不等于行业 |
| 企业宣称 | 企业营销页、发布稿或未独立核验的经营说法 | 企业称某功能、交付或用户指标达到某水平 | 不写成第三方证实，不将宣称的终身用户当活跃用户 |
| 估计 | 由公开数据或明确假设计算的结果 | 在这些输入和假设下得到的区间、敏感性 | 不称实测、不以计算精度掩盖输入不确定性 |
| 研究推断 | 从证据形成的解释、机制或判断 | 可能成立的需求机制、机会条件与反证 | 不把相关性当因果，不把资料缺失当负面经营事实 |

<a id="method-price"></a>
## 四、价格与经营证据纪律

每个价格观察保存原币种、地区、日期、具体版本、官网/零售/众筹等渠道、常规或促销、含税状态、运费、订阅和必需配件。缺失项写“未披露/待核对”，不能默认含税、包邮或免订阅。不同地区价格不在无汇率来源和同日基准时换算；即使换算，也不能据此声称具有相同可支配收入负担。

经营证据按实际指标记录：宣布、预售、众筹筹款、承诺交付、已交付、渠道铺货、终端销售、活跃、续费、复购、退货、售后、召回、停止服务，各自不互相替代。评价数量、搜索热度、融资、社交传播和筹款不能充当销量。即使已知筹款额和某一档价格，也不能相除得出订单数或出货量。

首次购买证据与留存证据拆开。礼物、外观、IP、技术新鲜感可以作为待检验的首购机制；重复互动、内容更新、社交关系和习惯可以作为待检验的留存机制，但在证据到达前都不是行业结论。没有公开留存数据时明确未知，不能从评论、发布频率或长年在售倒推留存率。

<a id="method-economics"></a>
## 五、可复核单位经济模型方法

### 5.1 先固定经济主体和计量单位

每个模型只能对应一个主体、一个地区、一个渠道、一种币种和一个设备/客户批次。品牌 DTC、品牌批发、ODM、AI 服务商和经销商分开建模，不能在同一利润行里同时拿品牌零售价、ODM 成本和平台抽佣。报表利润只在公开披露且口径一致时引用；下面模型输出仅是条件式贡献，不等于任何企业的实际利润。

以“一笔支付并发货的设备订单”为硬件单位，以该订单关联的服务账户为后续队列单位。退货、换新、多设备共账户和多人共设备分别处理。注明是否排除未发货取消订单；不得拿留存设备分母配全部发货成本而不解释。

### 5.2 硬件单笔预期贡献

```text
R_hw = E[商品实收 + 向客户收取的运费 - 折扣 - 退款 - 代收代缴税]
C_hw = 采购/制造成本 + 入境物流与关税 + 出库物流与包装
       + 支付/渠道费用 + 预期逆向物流与检修处置成本
       + 预期保修与换新净成本 + 单位许可/版权费用
       - 可回收退货库存价值
CM_hw = R_hw - C_hw - CAC
```

`E[]` 表示按明确事件概率求期望；若实收已扣折扣或平台结算已扣手续费，对应项目不能重复扣除。制造成本与采购价择一使用，不能再叠加供应商利润；一次性模具、认证和研发原则上列固定成本，若单价已摊入则记录并从固定成本扣除。回收价值受可售状态、整备成本和后续售价约束，不得把退货当作全额新品回库。

若仅用于演算且假设每笔都是同一未税商品价 `P`、退货全额退款、无部分退款或折扣、无运费收入，可写 `R_hw = (1-r) × P`。必须把这些条件紧邻公式声明；实际条款不符时回到事件模型。`r` 无公开依据时不能填入所谓“行业平均退货率”。

### 5.3 云服务、订阅和持续支持

```text
s_t = 第 t 期仍有服务义务的原始订单比例
p_t = 在有服务义务队列中，第 t 期产生实际付费的比例
R_sub,t = s_t × p_t × 第 t 期净订阅收入/付费账户
C_service,t = s_t × [免费与付费用户加权的推理、语音、存储和带宽成本
                     + 内容安全、客服与持续服务的单位变动成本]
CM_life,H = CM_hw + Σ(t=1..H) [(R_sub,t - C_service,t) / (1+d)^t]
```

`H` 为明示测算期限，`d` 为与期间一致的折现率，均是模型假设。`s_t`、`p_t` 与使用强度分别建模；免费账户也可能产生云成本，订阅流失不能自动等于服务义务消失。设备退货账户如何关闭、预付订阅如何退款、免费期、恢复订阅、离线模式和停服责任都需要独立条件。

不把“订阅收入/流失率”机械等同 LTV；在队列不成熟、使用非稳态或服务有免费层时，必须逐期列队列。只算有限期限时显示期限尾部的未覆盖义务，尤其不能在承诺长期或终身服务时将尾部成本设为零。

### 5.4 固定投入、现金与敏感性

固定投入单列研发、模具、测试认证、内容/IP 最低保证金、区域本地化、后台及安全运营固定人员等；不得把缺失的固定投入默认为零。贡献为正仍不代表净利润为正，也不代表现金安全。

当同一产品、渠道和期间的单位贡献 `CM` 为正且暂时固定时，静态贡献盈亏平衡量为 `N_BE = F / CM`。若 `CM <= 0`，这个公式没有可达的正向盈亏平衡量。该模型不包含规模引起的价格、质量或获客变化；不把结果当销量预测。

现金另按期间列订金、供应商付款、在途及库存、渠道账期、平台留存、退款、保修和订阅收款。众筹到账不是利润或履约完成，预收长期服务费用不等于服务当期已经赚取。

后续至少检验售价/折扣、退货、制造或采购、获客、使用强度、云单价、付费转化、续费、售后及服务期限。采用保守/基准/有利情景时逐项公开输入；相互关联的变量联合变动，不把“售价最高、成本最低、留存最好”拼成无条件基准。没有依据的输入只用明确假设，不冠以行业平均值。

### H02｜DTC 设备订单与二十四个月服务：纯假设演算

**性质：研究演算，不是公开产品成本、实际价格、利润或行业均值。** 日期2026-10-10；币种人民币，未税；单一假设DTC主体；每笔支付即发货，订单不含多机共享账户、部分退款或另收运费。无需汇率换算。以下参数全部为便于复核的研究假设，没有伪造供应商报价。

| 参数 | 基准假设 | 定义/不确定性 |
|---|---:|---|
| P | 599元 | 未税商品实收，未另扣折扣；不是任何竞品价格 |

| 采购 | 190元 | 不再叠加制造BOM或供应商利润 |

| 出库包装 | 20元 | 每单，退款也已发生 |
| 支付费 | 支付额3% | 假设退款不返还手续费，按原始599元收费 |

| 保修 | 每单15元 | 预期净成本，与退货处置分开 |
| 单位许可费 | 20元 | 假设按已发货单收取且不返还 |
| 退货可回收净值 | 每件100元 | 已扣整备等成本的假设净回收价值，不当全新库存 |
| CAC | 每单70元 | 按已发货支付单归因，不按留存账户分母 |
| F | 300,000元 | 纯假设固定投入，不含在采购单价中；不是项目预算或采购授权 |
| H、d | 24个月、0 | 有限期限且不折现的演算，不代表期末义务结束 |
| s_t | 0.92×0.97^(t−1) | 首期未退货队列，每月保留97%；服务义务比例不等于登录活跃率 |
| 付费比例p | 服务队列的20% | 包括免费账户成本，不用付费者分母算全部云成本 |

### H03｜低成本验证建议：预设条件而非已做实验

**性质：研究设计假设；本轮未招募、未联系、未测试、未收费或购买。** 后续实际执行须另获授权，涉及儿童需监护人同意、安全和数据最小化，不为实验绕过准入。

- 家庭建议：12个家庭、4周、以本地非量产演示比较既有玩法，观察后两周是否每周至少两天有无提示重复使用。示例继续门槛为至少8个家庭达到该行为且至少6个家长认为较已有方案有明确改善；缺访或数据不完整单列，不自动计通过。任何安全、权利或未成年人数据问题立即停止。样本小，仅决定是否开展更严谨试验，不外推市场比例。
- 成人建议：12位明确18岁以上参与者比较同一原创/已授权角色的静态、动作、对话版本，平衡展示顺序；先记录选择与理由，再明确是假设交易的愿付差价。若新增电子体验没有超过可复核增量成本的付费路径，或只在首次展示被选择，不扩大硬件投入。口头意愿不等于成交。
- ODM/服务B2B建议：先用共同任务书制作可验证文档、断网降级、维修或合成对话评测，不使用真实儿童数据；报价为模拟，须另获授权才接洽客户。继续条件是可复用交付边界与客户愿付价值都有证据，定制/返修吞掉贡献则停止扩展。不能把供应商表示兴趣当合同。
- 渠道建议：先选一个国家做当地语言商品与服务信息理解测试，不收款；只有另获授权且可售性核验后才能做真实销售。实际测试需逐单记录净收入、费用、退款和服务负担，不用点击率替代成交、也不把后续广告或采购支出视为当前已授权。
- 全部机会的保守决策门槛：硬性合规/权利不满足即不推进；没有首购与重复价值证据不开模或囤货；生命周期贡献在合理不利假设下无可修复路径则缩小范围。上述门槛是研究选择，不是统计显著性或行业基准。

<a id="method-opportunity"></a>
## 六、机会筛选与反证框架

先检查硬性成立条件：产品/内容/数据是否合法可实施、权利是否可获得、渠道能否触达、服务义务是否可履行、单位贡献是否有可验证路径。未知不是通过，也不自动判死，应进入补证或低成本试验。

对通过初筛的候选机会，用需求强度、首购/留存证据、可捕获价值、资本与服务负担、渠道可达性、合规复杂度及反证强度作同口径比较。优先采用高/中/低/未知及理由；若后续使用权重评分，须说明权重是本研究偏好而非客观行业事实，并检验改变权重是否改变排序。

最终输出 3—5 个机会，覆盖品牌/IP、ODM/供应链、AI 服务或渠道中的多个环节；不是预先规定机器人整机优先。每项包含目标用户、目标地区、价值链参与者、证据链、未满足需求或效率缺口、成立条件、反证、低成本测试、投入上限或止损条件。另输出 2—3 个谨慎方向，以证据说明谨慎原因，而不是贴行业标签。

低成本测试应在开始前写清招募范围、首购指标、重复使用或续费窗口、成功阈值、失败阈值、隐私保护和停止规则。阈值若为本研究选择须明示假设，不伪装成行业基准。涉及儿童时先确认监护与数据最小化，不通过试验绕过法规。

<a id="method-compliance"></a>
## 七、区域合规接收矩阵

每个地区分别核对产品分类/年龄、机械电气与电池安全、无线/电磁兼容、化学材料、儿童隐私、语音与云数据、AI 内容、消费者权益/订阅、召回及持续软件服务。只列需要核对的议题，不代表每项对每款产品都必然适用。非联网产品与麦克风/摄像头/云账号产品不得混用义务。

法规接入后分为已生效且适用、已发布尚未适用、提案/征求意见、标准或认证要求、非约束指引；记录各自效力，不把提案当现行法，不把认证标识当全部合规。法定日期的歧义须回交 A2，而不是由 I1 自行补法。研究提供商业决策边界，不替代当地合规或法律意见。
