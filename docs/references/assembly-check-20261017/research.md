# 机械装配对位调研（2026-10-17）

## 问题

用户装配右脚（14 号右踝，飞特版打印件）：发现舵盘 4 个螺孔相位"不正"，装上脚掌后无法做到脚掌与舵机（小腿）视觉垂直，质疑装配角度要求。

## 查证结果

1. **"装配前通电归中位再锁紧"是上游唯一明文要求**（CAD 仓库 README 摘自 21 页安装说明书）；本机已按此执行（mid 工艺，14 号转 2048 后扭矩锁定装配）。
2. **"2048 时脚掌与小腿垂直"无文档依据**——系会话中推断，已向用户撤回修正。关节角 0 对应的物理姿态由装配+孔位设计决定；踝关节存在设计预偏角的可能性未排除。
3. **正确的对位标准 = 结构件孔位与舵盘孔位对齐**（打印件按舵盘实际孔位设计）：25T 花键 14.4°/齿，逐齿位试装，4 螺孔全部顺畅穿入即为设计位置；25 档全部对不上才判件/舵盘不匹配。
4. 上游相关背景（replica 构建日志 2026-09-12/13 + CAD 仓库）：HD-1910 舵盘凸 vs XL330 舵盘凹，8 个配合件改模；**用户确认使用飞特版件**（v2.1 对应），此嫌疑排除。
5. 装配参考资料：
   - CAD 仓库 https://github.com/fanhao375/microduck-replica-cad（说明书 PDF / 装配 BOM / 组件图 23 张 / STEP）；
   - 组件图 `组件图/15-右踝脚.png`（左脚为 `06-左踝脚.png`）；
