# 当前供电与 HAT V1.2 实物复核

日期：2026-10-10。来源：本会话供电分析、用户关于 LDO/VBATT/舵机分支及 HAT 实物的追问。本次只读资料与照片、制作标注，**未进行本机通断测量、上电或带载测试**。

## 结论与适用范围

2S 直供舵机、HAT 降压供主控、IMU 板载 LDO 供内部电路的架构方向可继续评估；[v2](../../power-architecture-v2.md) **不是已经验证的 V1.2 接线方案**。本记录补充并纠正其接入口、分支和保护方面的前提，不代表全部历史资料已完成审计。

### 电压、电流与保护

- [HD-1910-C001 厂商规格书](../../../references/microduck-replica/tools/FeeTech_HD1910M_Servo/HD-1910-C001串型规格书20260907.pdf)（2026-09-07，PDF 第 3 页/印刷 2/7 页）给出工作电压 4–8.4V；7.4V 时静态 20mA、空载运行 ≤210mA、额定负载 900mA、堵转 2A±10%。15 颗简单相加分别为 0.30A、≤3.15A、13.5A、名义 30A；不是实测步态电流，也不是 8.4V 规格。
- 社区 banana_pcb README 的“正常运行 3–5A”不是本机测量或峰值上限。主控输入电流另计：例如 5V×1A、效率假设 90%、电池 7.4V 时约 0.75A，仅为估算。
- 5A 保险只是候选，需要匹配线材/接头、启动峰值、动作曲线和直流分断能力，不能保证保护 3A 支路。电池保护板及放电能力未验证。
- [飞特补丁说明](../../../references/microduck-community-kit/firmware/v1/patches/README.md)可确认扭矩使能、位置控制、Kp/Kd 设置，本次未找到整机 5A/6A 硬限流的证据。“靠软件力矩限幅兜底”不能作为硬件保护结论。
- 电源模块的稳压支路空载测试不能证明 PWR OUT 直通路径的载流能力；MAX 6A 丝印不能替代路径、端子、温升与适用范围核验。
- 6.6V 是参考停机阈值，上游明确要求换飞特后复测；不是电池不会低于的天然下限。舵机冲击负载可能使同源主控/IMU 掉电。示例：回路 0.1Ω、5A 时压降 0.5V、损耗 2.5W，仅为计算。

### LDO 与 VBATT

- VBATT 为电池电源网络名，不是固定的 5V/3.3V。按[IMU 网表](../../schematics/imu-to-dxl-scrapmeta-v0.3/hardware-netlist.md)，J1/J3 pin2 接 VBATT，再经 U3 AP2210K-3.3 生成 3.3V，供本板 MCU、IMU 与总线芯片。
- U3 位于绿色板下部、竖排 IMU2DXL 丝印左侧，五脚封装；不是中间的 U2 MCU 或 U1 传感器。型号依据归档设计，不是照片读出了芯片完整丝印。
- 旧标注中“输入上限 5.5V、只能 5V”的要求已被 v2 撤销。v2 引用 13.2V，本次尝试访问厂家 `https://www.diodes.com/assets/Datasheets/AP2210.pdf` 返回 HTTP 403，未重新取得原厂手册，不能宣称本轮独立复核过全部电气极限；实物料号、3.3V 和温升仍待确认。
- [U3 位置图](../../photos/imu-ldo-location.png)基于[旧实物标注原件](../../schematics/imu-to-dxl-scrapmeta-v0.3/实物板元件标注.jpg)重新圈示并去掉错误电压说明。旧图只供来源追溯，不再作为电压接线依据。

### 舵机链、分支与实际接入口

- 舵机一颗接一颗是物理菊花链；电源负载实际并联，通信共用 DATA、按 ID 寻址，末端无需接回 HAT。
- 两条支路各占一个输出口，不要求四个输出口；但电池输入也必须有位置。若电池占用 HAT 两个 SERVOS 口之一，只剩一个口接舵机链，不能同时假设两口都作支路输出。
- IMU 可作为链末节点，不必独占 HAT 口；避免未经载流验证就让 IMU 板穿过整支舵机动力电流。
- 分支只能降低各支路前段电流，不消除总入口/公共铜箔的瓶颈，也不保证均流。是否分支需结合实测和配电结构决定，不要求用户立即改线。
- C001 规格书 PDF 第 4 页/印刷 3/7 页写 AMP2.0-3P、按其图示编号 1=Signal、2=VCC、3=GND；当前 BOM 的 5264 与 HAT 的 EH 说法存在差异。可能涉及批次、系列、视角，须逐针核验，不能靠“能插入”判断兼容或直接要求翻线。

### HAT V1.2 正反面照片复核

原图：[正面](../../photos/hat-v1.2-front.jpg)、[背面](../../photos/hat-v1.2-back.jpg)；本轮标注：[接口复核图](../../photos/hat-v1.2-port-review.png)。

1. 正面明确看到两个已焊接 SERVOS 3Pin 插座，没有识别到明确标注 BAT/VIN 的独立电池入口。不能由“没看到”证明电路上绝对不存在其他接入位置。
2. 相邻两组空焊位各 4Pin；按[存档 V1.0 第 4 页](../microduck-hat-20261006/page4.png)为 RS485 接口位置，V1.2 电气定义仍待核实。
3. 背面八个焊盘的位置、排列对应上述两组 4Pin 空焊位，不能另外算作一组已确认的独立电池输入焊盘。此前“疑电源输入”的猜测不再作为接线依据。
4. 正面圆柱电容可见“10 / 50V / RVT”标记，更符合普通电解电容；此前“1.0F 5.5V 超级电容/RTC 备份”的判断没有可靠依据，撤回。具体电容规格仍以器件资料为准。
5. 背面有 MCU 类器件，而 V1.0 图无对应 MCU；完整型号、用途和固件尚未确定，不能据照片推定电源时序或总线功能。
6. 撤回此前未经验证的“电池从独立入口进 HAT、两口各挂一条舵机链”施工建议。先取得 V1.2 图纸或断电核对网络；不得向未知焊盘接电。导通不等于载流合格。

### 回答与限定

- **功能拓扑正确、条件式认可，不是实物接线放行。** 按存档 V1.0 的同网电源/5V 降压/半双工电路，可用一个 SERVOS 座作电池网络输入，另一个作下游总线。官方 HAT“从电机接口取电”的历史来源见[电池调研](../microduck-battery-20261008/research.md)，不拿官方版本替代本机 V1.2 验证。
- 图中 A（照片左 SERVOS 座）拟接 +BATT/GND 两线、DATA 留空；B（右邻座）三线连接舵机链，IMU 的 J1 在链末、J3 留空；C 是背面黑色 40P 排母，对插 Radxa Zero 3W。
- A/B 是示意分工，不是实物端口固有方向。只有 V1.2 两座同网、针序与路径核准后才可互换；**未根据照片猜测上/中/下针极性**。不将示意箭头作为具体针脚接线图。
- 40P 为主控提供 HAT 降压后的 5V 及 UART/地等连接；电池原压不能接 40P 的 5V、IMU J2 的 3V3 或数据线。未确认防倒灌时不同时 USB 供电；所有对插断电进行，确认 pin1 与方向。
- HAT 电源/通信工作正常后，微雪总线转接板和独立稳压板不需要装入正常整机；微雪保留台架调试用途。banana_pcb 取电、线材/端子、过流保护、匹配充电器仍需，不是“电池裸线随便接上”。
- **当前入口载流是阻止直接整机上电的重要问题**：A 承担整机电流，B 承担下游舵机链/IMU 电流；现有 EH 约 3A 额定与社区常态 3–5A 已有潜在不匹配，额定不足先改配电，不进行超额负载试验来证明可用。保留原稳压模块不能自动消除末端 HAT 入口瓶颈。

## 本轮：过流保护的落地方法（2026-10-10）

用户问“过流保护怎么做”。本轮基于已归档的供电、电流预算与入口风险提出工程建议，未开展新的厂家/商品检索，未选择具体保险或保护板，未进行任何故障测试。

- 形成[过流保护方案](../../overcurrent-protection.md)：正极靠近电池出线串主保险、后接额定合适的直流总开关；负极接 GND。保险不能横跨电池两极或接 DATA，保险前的取电线/触点仍需绝缘和机械保护。
- 保险安数暂不定：需要实际电流/峰值、连接器和线材额定、温度降额、动作时间/I²t、直流额定和分断能力。3A 或 5A 都不意味着刚超过就立即切断；不能用“5A 保险”证明 3A 接头安全。
- 区分保险、PTC、电子断路器、BMS 与软件控制。电子保护建议评估限流、超时锁断及人工复位，需核验热设计、反向回灌与欠压重启问题，不直接推荐无资料的商品板。
- 若 HAT EH 入口确实不能满足整机需求，应先改配电/入口，支路保护与总线供电避免旁路；没有现场网络核验，不给出绕过未知针脚的施工接线。
- 本页内容为设计建议，不是已验证的本机保护。采购状态仍为待定，新增总开关/断电连接件条目；没有买入或下单。
- 没有新增用户图片或图片产物；现有 HAT 意向图中的“保护”模块由此文解释。与本任务无关的市场调研目录保持不动、不提交。

## 本轮：先确认堵转烧板问题是否存在（2026-10-10）

按用户要求收窄为风险存在性审查，见[专门核查](../stall-hat-risk-20261010/research.md)。结论：接头/铜箔过流发热机理成立，但尚未证明本机一次短时堵转会损坏；不能将 EH 3A 与社区 3–5A、或主控降压 2A 当作瞬时烧板判断。直接核对 C001 厂商规格书 PDF 第 5 页发现**过流卸载出厂默认关闭**、超阈值持续 2s 后关输出、位置指令清除标志；社区 16 台固件 3.46 回读及工具默认关闭相符，不等于本机配置已知。暂不预设加配电板，先只读回查保护/模式与 V1.2 电流路径。没有任何上电、改参数或故障实验。
