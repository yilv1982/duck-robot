# IMU 板②（jyg9 GD32 社区版）台架验收单

> 2026-10-14 建。对象：**单 3P 口**的 IMU 板，照片判别为 jyg9 / microduck-community-kit 成品版（GD32F303 LQFP48 + 降压前端），判别证据与照片存档见 [IMU 版本调研](./references/imu-to-dxl-variants-20261009/research.md) 补充节及 [照片索引](./photos/README.md)。
> 与板①（ScrapMeta v0.3）的区别：**本板免刷固件**（出厂 DXL 2.0 + 飞特双协议自动识别，ID 200）；**供电 6~24V 宽压，台架严禁用 USB 5V 直喂**（低于输入下限，可能不启动或工作异常）——这点与板①刷机阶段"只给 5V"的红线恰好相反，两块板不要套同一份供电习惯。
> 补充（2026-10-14 用户问"5V 能不能测"）：**5V 不会损坏本板**（欠压不伤 24V 耐压的降压电路），若手头只有 5V 可短暂试机看是否点亮；但降压芯片型号照片不可辨、实际最低输入未知，5V 下"能跑"不证明 8.4V 正常、"不能跑"也不证明板坏，**验收一律在 7.4V 做**。
> 本单只做**台架通信验收**，不做整机带载；结果不代表装入整机后的表现。

## 前提与物料

| 物品 | 说明 |
|---|---|
| IMU 板②（单 3P 口） | 免刷固件；实物针序未核，先核后电 |
| 德力西可调电源 DLX-30V10AMF | 台架供电，**设 7.4V、限流 0.2A 起步**（6~24V 输入范围内、对齐 2S 电池标称） |
| FE-URT-2（或微雪转接板 B 模式） | 总线主机；URT-2 只过 DATA/GND，**不从它取电**（与板①验收接法相同）；用微雪则其 DC 输入喂 7.4V/2S，**严禁 12V** |
| 杜邦母头线 / EH 3P 线 | 板座为 JST EH 3P（2.5mm）；过渡用杜邦母头套座针（2.54 兼容 2.5），胶带固定防松 |
| 万用表 | 核针序、核电源空载电压、测通断 |
| 电脑 + `flash/2-查COM口.bat`、`flash/3-验收-imu200.bat` | 验收工具与板①共用；imu200 的 13 项判据（ID 200 在线、@56 读 15 字节、四元数范数、陀螺量程、计数递增、不冻结、sync_read 时延等）对 jyg9 固件同样成立（同一契约） |

## 步骤

| 顺序 | 做什么 | 通过判据 |
|---|---|---|
| 0 断电核线 | 全部断开。按 [三板舵机座对比](./photos/board-servo-socket-pinout.png) 核对板座针序（推断 1=GND 2=V+ 3=DATA，**照片推断，需实物确认**）：蜂鸣档确认 GND 脚对板内地网连通、V+ 与 GND 之间无短路；电源输出关闭状态下预设 7.4V / 0.2A，复核正负 | 针序明确、无短路；电源空载输出 7.4V 左右。针序无法确认则停止，不上电试错 |
| 1 空板供电 | 只接 V+/GND 两线（DATA 悬空），开输出 | 电流稳定在几十 mA 量级、无持续顶限、无异常温升；板上有指示灯则记录状态。顶限或发热立即关输出排查 |
| 2 接总线 | **关输出**，接 DATA/GND 到 URT-2（V+ 仍走可调电源，共地）；URT-2 插电脑 USB，`2-查COM口.bat` 记 COM 号 | 接线完成后再开输出；无异常电流变化 |
| 3 imu200 验收 | 双击 `3-验收-imu200.bat`，输入 COM 号，跑 13 项检查 | **全 PASS = 主控 robotd 飞特补丁会认这块板**。日志自动存 `tools/imu200/logs/`；有 FAIL 保留日志发回来逐条判 |
| 4 晃动验证 | 验收通过后在工具读数期间轻晃/翻转板子 | 四元数/陀螺读数随姿态连续变化、不冻结、无丢帧突增——确认真 IMU 数据而非静态缓存 |

## 停止条件与边界

- **停止条件**：针序不明、上电持续顶限、异常温升/异味、验收中反复掉线。不要盲目加大限流来"通过"。
- **本板未见 CH340/USB 调试口**（与早期调研"jyg9 版带 CH340"有出入）：台架上没有调试日志可看，判别全靠总线侧；固件升级后续走社区 `upgrade.py` 总线在线升级，本单不涉及。
- 出厂固件版本号未核（可在验收日志的应答包里找版本寄存器，或后续用社区主机工具读）；发现版本过旧再决定升级，不擅自刷写。
- 验收通过只证明"总线从站合格"；装入整机（挂 8.4V 总线末端、与 15 颗舵机同链 sync_read）按 [HAT 验证单](./hat-v1.2-test.md) 第 4 阶段整链通信执行。
