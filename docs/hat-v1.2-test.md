# HAT V1.2 接线与分阶段验证单

> **2026-10-10 修订**：本单取代旧版“扫描背面八焊盘找电池入口”“超级电容”“蜂鸣导通即可过 3–5A”“一颗舵机 ping 通即可整机放行”等不成立的判据。
> 当前只有 V1.0 图纸，实物是 V1.2；未有本机电气验证结果。先取得相符图纸/板卡来源说明，或由具备测量条件者核清网络。**身份或极性不明不接电池、不向未知焊盘送电。**

接线意向图：[hat-v1.2-wiring-plan.png](./photos/hat-v1.2-wiring-plan.png)。[供电方案](./power-architecture-v2.md)与[证据记录](./references/power-review-20261010/research.md)。

## 候选接法（尚未放行）

- 图中 **A** = 照片左侧 SERVOS 座，拟接电池 +BATT、GND 两线，DATA 脚留空并绝缘。
- 图中 **B** = 相邻 SERVOS 座，三线接舵机链，IMU J1 接链末，J3 留空。
- 图中 **C** = 背面 40P 排母，对插 Radxa Zero 3W。只从 HAT 获取正确的 5V，不给 40P 直接送电池原电压。
- A/B/C 是图示编号，不是丝印或厂家输入/输出定义。核验两座电源同网、针序一致及路径合格后，A/B 才可交换角色。
- V1.0 图定义 SERVOS pin1=GND、pin2=+BATT、pin3=DATA；**不能由正面照片直接认定上下针序**。HAT、线缆两端与舵机/IMU 的插合视角分别核对。

## A. 断电核对（电池、USB、主控、舵机、调试器全部断开）

- [ ] A1 记录 HAT 版本、两座位置、实际连接器系列及观察方向。以已确认的 40P GND 或明确地网络作参考，核实两个 SERVOS 座的 GND；**安装孔不默认接地**。
- [ ] A2 核实候选 +BATT 与板内降压输入网络的关系，以及两座 +BATT/GND 对应连通。检查是否串入开关/保险等元件；未取得图纸时不能仅靠蜂鸣排除其存在。**导通只验证网络，不验证载流。**
- [ ] A3 核实 DATA 与电源没有误接，测量电源对地是否存在可疑持续低阻。电容充电、保护器件会影响表读数，不把“响/不响”单独当结论。
- [ ] A4 背面八个焊盘对应两组 4Pin 空位，不是另发现的电池入口；本方案不用这些焊盘输入。圆柱电容读到“10 / 50V”，不按超级电容或 RTC 电源处理。
- [ ] A5 对电池取电线及舵机转接线逐端确认 +BATT、GND、DATA。电池到 A 只装两根供电导线；杜邦信号线不作整机动力线。电池原压不能接 DATA、IMU J2 的 3V3 或 HAT 40P 的 5V。
- [ ] A6 核验 Radxa 对插方向、pin1、排针高度、间隙与外壳，避免旋转/错位。确认主控 USB 与 HAT 同时供电是否获支持；未确认就只留一种供电路径。

**A 阶段无法确定针序、电压或网络时停止，不能靠上电试错。** 不用表笔扫 MCU 密集引脚来证明“不干扰”；隔着缓冲器/电阻的电路不会因不蜂鸣就不存在。

## B. HAT 空板台架（不是电池直接首次上电）

- [ ] B1 在 A 阶段已核实后，使用可限流台架电源，不接电池、不插主控和舵机；初测采用 7.4V，空板限流 0.3A 作为诊断起点。设定与接线在输出关闭时完成，复核正负再开输出。
- [ ] B2 测 40P 5V 轨初检约 5.0V（以主控和器件规格为最终判据），记录输入电流、供电状态、异常温升。持续顶限/电压塌陷立即关输出排查；可能是浪涌、限流不足或故障，不能直接断言短路，更不能盲目加大限流。
- [ ] B3 验证工作电压范围端点前先确认全部器件允许值，再检查 8.4V 下的 5V 输出；低端测试以实际电池/系统停机阈值为准，6.6V 仅是待校准参考。
- [ ] B4 不用“空板 DATA 必须是 3.3V”作为此阶段判据：V1.0 的 +3V3 可能来自对插主控，空板总线驱动可能未供电。禁止向 DATA 强灌电压。

## C. 逻辑与通信（每次增减插接件先关输出）

- [ ] C1 先断电对插 Radxa，按已确认的主控需求与线材能力重新评估限流；空板 0.3A 不作为主控启动配置。检查启动时 5V 波动、输入电流，确认串口设备与占用状态。
- [ ] C2 主控供电稳定后核验 HAT 的 3.3V 和 DATA 空闲电平、UART2/半双工路径，若与 V1.0 不符先查来源说明。不仅靠万用表平均电压判断协议波形正确。
- [ ] C3 IMU 在独立限流台架确认实物 LDO、VBATT 输入、3.3V 输出及温升，再刷写匹配固件并做 imu200 验收；本步骤需要的 SWD 调试器不属于整机常驻链路。
- [ ] C4 先接一颗 ID/波特率已确认的舵机，初始扭矩关闭，确认可通信且无异常动作；之后连接链末 IMU 验证唯一 ID（IMU 200 不与舵机冲突）。连接器与针序核对优先于软件调试。
- [ ] C4a **先只读回查舵机保护**：对应型号/固件核验 19 的 BIT3、28 保护电流、38 延时和 33 模式，并核对运行软件对 RAM 目标电流/限幅的改写；不运行会写默认配置的初始化来代替读取。C001 手册过流出厂默认关闭，社区工具默认亦关闭；没有回读前不声称“堵转瞬时保护有效”，不擅自写保护参数。见[风险核查](./references/stall-hat-risk-20261010/research.md)。
- [ ] C5 MCU 功能需板卡说明或信号测试确认；静置无异常或 ping 成功不证明 MCU 永不影响总线。异常动作/总线冲突先停，不据此直接认定 MCU 是根因或自行断脚。

## D. 配电验收（独立于单节点通信验收）

- [ ] D1 查实际 A/B 座及压接端子、线规、banana 触点、主保险、HAT 公共铜箔能力；A 入口承担主控、舵机和 IMU 的总电流，B 承担下游链电流。
- [ ] D2 当前资料采用 EH 约 3A 额定，而社区整机常态参考 3–5A，是需要核验的潜在不匹配，**不是一次短时过流必然烧毁的证据**。**在额定不满足时先改配电，不通过超额带载去“试是否能扛住”。** 5A 保险不能保证保护 3A 连接器。
- [ ] D3 在已核准额定内逐级增加负载，记录稳态/启动峰值、接头与线材压降、温升以及主控/IMU 是否重启；不做整机堵转测试，台架面板平均电流不能覆盖快速尖峰。
- [ ] D4 保护/入口条件不足时，改用经设计确认的配电或大电流入口。简单保留旧稳压板或把两口并接不能自动解决该瓶颈。

## 收尾判据

记录各阶段测试条件和结果到 [PROGRESS](../PROGRESS.md)。

- A/B/C 通过：只能说明候选连接关系、逻辑供电与受测节点通信可用，**不是整机放行**。
- D 通过且电池、保护、接线、低电量处理已核准：才评估整机上电。
- HAT 逻辑链路不适配：微雪板可作台架/替代架构候选，重新设计主控供电，而不是直接照本图替换。
