## 当前执行安排

1. **主线不变**：电池取电/保护 → HAT A 口；B 口 → 舵机链 → 末端 IMU；C 排母 → Radxa。微雪板只留台架调试，独立稳压板不作为整机必需件。
2. **暂不新增架构任务**：dxl_hub、电子保险或独立动力支路都是备选，不因前述风险讨论自动采购或实施。
3. **先做基础测试**：按[HAT 测试单开头的简明清单](./hat-v1.2-test.md)从空板到单节点、整链通信、支撑下低负载动作分级进行；保留各阶段输入电流、5V/3.3V、通信、温升与重启记录。
4. **问题驱动排查**：若发现持续限流、明显压降/重启、异常发热、动作异常，或已确认负载超过实际通路额定，停止本阶段、查明原因，再决定修线/参数/配电等措施；不以“试到烧坏”为依据。
5. **测试范围分清**：基础检查用于排除明显错误和供电/通信问题，不保证堵转、故障短路或所有步态峰值都安全；不做故意堵转/短路，不未经回读擅改保护。

## 风险判断先于配电改造（2026-10-10 补充）

**目前没有证据证明本机 HAT 会因一次短促堵转烧坏。** 舵机电流按现有图纸走电池直通接头/铜箔，不经过 5V/2A 降压输出；EH 的参考额定也不是瞬时烧毁阈值。损坏取决于总电流、持续时间、重复率及实际通路耐受，不能只用 3A 与社区 3–5A 比较作结。

更直接的待核点：HD-1910-C001 厂商规格书明确过流保护**出厂默认关闭**，描述为超阈值持续 2s 后关输出，且新位置指令可清除标志；社区回读与工具默认配置也说明不能假定过流卸载已经启用。这不是用户实物回读结果。先核实保护位/阈值/延时/运行模式及 V1.2 电流路径，暂不把加 hub 当作既定任务。详见[堵转风险核查](./references/stall-hat-risk-20261010/research.md)。

## 对用户所述流程的确认

**功能拓扑正确，有条件采用：** 电池原电压进入 HAT 的电池网络；HAT 接舵机链和链末 IMU；HAT 背面 40P 对插主控并提供 5V 与 UART 链路。若 HAT 电源/通信功能验证通过，微雪转接板和独立稳压板可以不装入整机。

“直接进 HAT”仅指**不经过独立稳压器**，不是省略取电连接、合适的线材/接头和保护。当前候选接法将一个 SERVOS 口用作电源入口，不再假设另有独立电池入口。

## 拟采用的两口分工（不是两条舵机支路）

```
NP-F550 2S 电池（满电 8.4V；型号/能力待实测）
  │ + / −
banana_pcb 取电 → 适配线材、接头及保护（正极保险靠近电池）
  │ + / −；不接 DATA
  ▼
HAT 的 SERVOS A 口（候选入口；针序和载流待确认）
  ├─ 电池网络 → 板内降压 → 5V → 40P C 排母 → Radxa Zero 3W
  │                              同时连接 UART 等逻辑信号
  └─ SERVOS B 口 → 舵机 1 → 舵机 2 → … → 舵机 15 → IMU J1
                    共用 +BATT / GND / DATA            │
                                               U3 → 3.3V
                                               J3 留空
```

- A/B/C 是示意图编号，不是实物 CN 编号或出厂输入/输出定义。只有核验两座电源同网、针序一致及路径合格，才可交换 A/B。
- V1.0 图上 SERVOS 是 1=GND、2=+BATT、3=DATA。**本图没有根据照片指定上/下针的极性**，不同插合视角分别核清。电池两线仅接已确认的 +BATT 与 GND；DATA 留空、绝缘。
- 舵机虽物理串成菊花链，电气负载是并联、数据按 ID 寻址；末端不用返回 HAT。IMU 放末端避免其小板承载整条舵机链电流。
- 电池不能接主控 USB、HAT 40P 的 5V、IMU J2 的 3V3 或 DATA。两组 4Pin 空焊位本方案不用，不凭照片认定为备用电池入口。

## 与社区原方案的区别

上述单链是本会话针对用户流程的最小功能意向，**不是社区 C 已公布的配电路径**。社区实际 README 使用 `电池 → banana_pcb → dxl_hub → 头部/左右腿/IMU`；本轮 PCB 核对确认 hub 有独立两线 J3 电源焊盘，但未见板载保险，载流/温升报告仍缺。若 HAT 入口额定不足，优先评估独立动力配电，让 HAT 不再承担全舵机电流；**这不要求把微雪/独立稳压板装回去**。不可把普通小 3Pin 输入分线板当作已解决总入口瓶颈，详见[方案比较](./references/power-distribution-comparison-20261010/research.md)。

## 各件的角色

| 对象 | 功能与当前判断 |
|---|---|
| banana_pcb、U6068 与取电线 | 保留；只取出电池原电压，不是稳压/充电/BMS。插针、极性、绝缘及载流需验证。 |
| HAT V1.2 | 拟同时承担主控降压供电与 UART 半双工总线适配。存档 V1.0 为 AP63205 5V/2A 与 74LVC 驱动；实物对应性和可用电流需验证。2A 是芯片级额定，不保证实际板子满载可用。 |
| Radxa Zero 3W | 断电后正确对插 40P，防反向/错位；从 HAT 5V 取电。未核准 OR-ing/防倒灌前，不同时 USB 供电。 |
| HD-1910-C001 ×15 | 工作电压规格 4–8.4V，2S 直供在范围内；不是通过 HAT 5V 降压给舵机。手头型号/线序仍待核实。 |
| IMU | 按归档设计，J1/J3 的 VBATT 经 AP2210K-3.3 生成 3.3V。实物 LDO 及电压/温升需确认，旧“必须另拉 5V”的要求已撤回；J2 的 3V3 不是电池入口。 |
| 微雪 Bus Servo Adapter (A) | HAT 数据链通过后不装入正常整机；保留用于单舵机设置/台架调试或另行设计的替代方案。 |
| BUS SERVO POWER SUPPLY V1.3 | 不再需要其稳压功能，可从整机删除；仅在转接方便时可选用 PWR OUT，但不能据空载测试认定其载流或保护合格。 |
| 保护、匹配充电器 | 仍需要；保险选型/动作曲线、连接器及电池 BMS 能力待核验。不用 HAT/USB 给 NP-F550 充电。 |

## 过流保护入口

基础方向：**电池正极 → 靠近电池出线的主保险 → 直流总开关 → 已核准的配电入口**，负极接 GND；保险串联，不跨接正负。保险安数、动作曲线与最弱通路尚未完成协调，不能直接指定 5A，也不能靠保险升级 3A 接头的载流。详情见[过流保护方案](./overcurrent-protection.md)。

## 待核风险：入口电流与持续时间

**一个 EH 口进电，会让该入口承受整机电流。** 当前项目引用 EH 约 3A 与社区“正常 3–5A”，这是核验裕量的线索，不是本机实测或瞬时损坏判据；单链首段/B 口也承担下游电流。须看实物额定与电流波形持续时间；未核准前不做全机过额负载试验。

HD-1910-C001 规格书 7.4V 工况：单颗静态 20mA、空载运行 ≤210mA、额定负载 900mA、堵转 2A±10%。15 颗简单相加分别为 0.30A、≤3.15A、13.5A、名义 30A；**不代表实际步态电流，也不是 8.4V 的测量值**，还未计主控。

- 若实际连接器/主入口能力不足，先换成经核准的配电或大电流输入设计；“保留独立稳压板”不自动改善最后经过的 HAT 小接头。
- 不把两个 HAT 口直接并接当作安全增流办法，也不能在 A 已作电池入口时再画成“两口各一条舵机链”。
- 主保险 5A 仅是原候选值，必须重新匹配最弱导线/接头、正常峰值和动作曲线；不是超过 5A 就立即断开，不能保证保护 3A 座。
- 目前没有已落实的主保险记录，电池 BMS 及过流阈值也未验证；不能声称已具备整机保护。V1.0 的 F1/D3 位于数据链而非动力链，不能当电源保险；V1.2 元件及网络另核。
- 未找到 robotd 将整机限制在 5A/6A 的硬限流证据；扭矩使能/降低 Kp 不替代硬件保护。
- 同源电压跌落可能令主控/IMU 复位。6.6V 仅是沿用的待校准低电量阈值，不是电池天然最低电压；需测启动/动态压降及低电量停机。

## 接线与版本边界

1. 照片只确认两个已焊接 SERVOS 3Pin 口和背面 40P 排母；未识别出独立 BAT/VIN 座。八焊盘对应两组 4Pin 空位，网络待核；圆柱电容不能称为超级电容。
2. C001 厂商规格书写 AMP2.0-3P，而旧记录写 5264；实际系列/批次与 HAT EH 的转接线逐针核对，不靠“试插能进”判断兼容。
3. IMU 的 13.2V 上限来自先前归档结论；本轮厂家 PDF 获取曾受限，未独立复核该数值，不将其当作整板允许电压。按实物完整料号/手册和台架结果判定。
4. 主控 +3V3 可能反向供给 HAT 总线驱动，空 HAT 未接主控时 DATA 不必已是 3.3V；相关验证顺序见测试单。

## 验证顺序

断电确认网络/针序 → HAT 空板台架限流测 5V → 对插主控测启动及逻辑轨 → 单独 IMU 取电/刷机验收 → 单舵机通信 → 在核准额定内逐级测负载/保护。**单节点 ping 通不等于整机载流通过。**
