>
> **2026-10-10 实物复核补充：本文是架构讨论基线，不是 HAT V1.2 已验证的接线图。** 照片未识别出独立电池入口；电池若占用一个 SERVOS 口，就不能同时把两口作为两条舵机支路。电流、保护及接插件仍待验证，详见[供电与 HAT 复核记录](./references/power-review-20261010/research.md)。

## 为何从 v1 改到 v2（改动说明）

v1 有两处事实错误，2026-10-10 评审时用器件手册与 HAT 原理图渲染图证伪：

### 错误 1：「IMU 板 LDO 上限 5.5V，插总线即烧」不成立

IMU 板 U3 是 **AP2210K-3.3**，数据手册最大输入 **13.2V**（Farnell / RS 参数页一致），2S 满电 8.4V 远在规格内。佐证设计意图的细节：

- 板子输入电容 C5 是 10µF/**50V**（[hardware-netlist.md](./schematics/imu-to-dxl-scrapmeta-v0.3/hardware-netlist.md)）——只吃 5V 的设计不会选 50V；
- 官方 HAT 的 Dynamixel 接口直出电池原电压，板上唯一的 5V 降压只给主控（replica BOM 核对结论）；
- replica 自绘 IMU 板专为 8.4V 总线选 30V 宽压 LDO（HT7533-1）+ 12V TVS + 25V 输入电容，输入电容直接挂总线；
- community-kit 的 IMU 成品板直挂 dxl_hub 电池总线，真机 15×HD-1910 + 50Hz 环路验证过；
- 热耗核算：8.4→3.3V × 约 15mA ≈ 77mW，SOT-23-5 温升十几度。

**后果**：v1 的「混血 3P 线」铁律与「改焊 5V 档 + 空载复验」任务都不是必须的——IMU 可以像舵机一样直挂总线。混血线还引入一个 v1 没看到的隐患：总线有电而 5V 支路断电时，数据线会经 R6 往未上电的 IMU 板灌电流。直挂则电与数据同源同插，不存在这个状态。

### 错误 2：「HAT 舵机口 +BATT 经 F1 自恢复保险 + 5.1V TVS」不成立

渲染 HAT 原理图第 4 页逐网络核对（渲染图存 [page4.png](./references/microduck-hat-20261006/page4.png)，源文件为同目录 5 页 PDF）：

- **F1（PRG18BB101MB1RB）串在数据线 pin 3 上**，D3（BZT52C5V1S）是数据线 5.1V 钳位；
- 舵机口 pin 2 的 **+BATT 完全直通，无任何保险**；
- F1 保持电流仅 **21mA**（跳闸 45mA，Murata 手册），是信号线保护器件，物理上不可能过舵机电流。

**后果**：v1 未定项「总线电流过不过 F1 保险」关闭——总线电流本来就不经过它。同时浮出 v1 没写的真风险：**整机电源链没有保险丝**（见风险节）。

### v1 中维持不变的结论

电源板空载实测数据（6V 档、稳压下限 ≈6.3V、PWR OUT 直通）、HAT 板内 AP63205 5V/2A 只供主控、舵机吃电池直通电压、舵机口针序 1=GND / 2=+BATT / 3=DATA 与 IMU 板 J1 同序、电源板丝印 MAX 6A 天花板、HAT 原理图 V1.0 与实物 V1.2 差异待确认。

## 一句话结论

**电池直通是唯一的动力母线：舵机、HAT、IMU 全部吃电池原电压；5V 只存在于 HAT 板内（给主控）。降压模块退化为可选的转接件。**

## 拓扑

```
NP-F550 2S 电池（8.4V 满 → 带载最低 6.6V）
  │
banana_pcb（U6068 插针 ×2 + 焊接出线，线径按 3-5A）
  │   ⚠️ 建议在此串 5A 保险丝（全链目前无保险，见风险节）
  ▼
[可选] BUS SERVO POWER SUPPLY V1.3 —— 纯转接：XT60 进 → PWR OUT 直通出
  │      （VCC 稳压口闲置，当前 6V 档不用动；拿掉它则自制线直连 HAT）
  ▼
HAT 的 +BATT 网络（实际接入口待确认）
  ├─ 板内 AP63205 降 5V/2A ──→ 主控 Radxa Zero 3W
  └─ 舵机口 CN11/CN12（JST EH 3P）直出 +BATT（无保险）
       ├─→ 舵机总线链：HD-1910 ×15（电池电压，真机用法 7.8-8.1V）
       └─→ IMU 板 J1（直挂总线，板内 AP2210K-3.3 自降 3.3V）
```

**分两支只是条件式配电选项，不是当前实物接线要求。** 必须先确认电池入口不会占用 CN11/CN12 且公共路径载流合格；否则保留单链或另评估配电转接。按项目引用的 EH 3A 额定值，单链首段承受全部下游电流；两支不保证均流，也不降低电池入口的总电流。社区“正常 3–5A”不是本机实测或峰值上限。

## 各板取电方式

| 板 | 电从哪来 | 接口与备注 |
|---|---|---|
| banana_pcb | 电池触点 | U6068 插针 ×2 + 拆电池焊接出线；线径 3-5A；建议串 5A 保险 |
| 电源板（可选） | banana_pcb 出线 | 仅作 XT60→螺丝端子转接；VCC 稳压口闲置，6V 档保持不动 |
| HAT | 电池直通（电源板 PWR OUT 或直连） | 板内 AP63205 降 5V/2A，**只够主控**；舵机口直通无保险 |
| 主控 Radxa | HAT 板载 5V | 经 HAT 板载供电，无需自行接线 |
| 舵机 ×15 | 总线电池电压 | 单链/分支待入口与载流验证；C001 规格书写 AMP2.0-3P，与此前 5264 记录有冲突，须核实实物型号、视角和逐针线序，不能只试插 |
| IMU 板 | **总线电池电压**（J1 pin2） | 板内 AP2210K-3.3（耐 13.2V）自降 3.3V；上电前台架验证一次 |

## IMU 板接线（取代 v1 三铁律）

J1 = JST EH 3P，引脚 **1=GND、2=VBATT、3=DATA**，与 HAT 舵机座同序。

1. IMU 是**普通总线节点**：J1 直插 HAT 第二舵机口或链上任一空座。叶节点 J3 空着即可；J1/J3 板内并联；未验证其穿板载流前，不让整条动力支路从 IMU 板穿过。
2. 数据电平两侧均为 3.3V（HAT 的 74LVC 驱动由 +3V3 供电，见原理图第 4 页），IMU 板的 D1/D2 与 HAT 的 D3 钳位正常工况都不动作。
3. **上电前一次性台架验证**（覆盖「实物 LDO 与设计文件不符」的残余风险，替代 v1 的改焊复验）：台架电源限流 0.1A，从 J1-2 给 IMU 板升压至 8.4V，确认 J2-1 的 +3V3 轨稳定 3.3V、U3 不烫。通过即闭环。
4. J2 调试口 pin1（+3V3）仍是板内 3.3V 轨引出，**不是供电入口**；烧录时仅作 DAPLink 电平参考（此条与 v1 一致）。

## 未定项与风险

- **全链无保险丝**：banana_pcb 纯直通、电源板 PWR OUT 直通、HAT 舵机口直通，从电池到舵机无过流保护，只靠 NP-F550 电池自带保护板兜底。建议 banana_pcb 出线串 5A 保险丝（fanduck 触点板即预留保险位，同思路）。
- **EH 座载流**：额定 3A vs 整机常态 3-5A，分支须先核实独立入口与公共路径；真实电流台架带载复测量。
- 电源板丝印 **MAX 6A** 的具体适用路径及直通口载流能力尚未验证，不能当作限流保护。15 颗在 7.4V 下的名义堵转电流简单相加为 30A（非实际步态电流）；未找到 robotd 将整机硬限流在 5A/6A 的证据，扭矩使能/增益设置不能代替硬件保护。
- HAT 原理图 V1.0 vs 实物 PCB V1.2 差异仍未确认（接线前向板卡来源索取 V1.2 图纸或改动说明，v1 已记）。
- HAT 供电链细节：LM5050 理想二极管在 buck 之后的 +5V 轨（OR-ing/防倒灌），PWR_DET 关机检测在 +BATT 上分压——与本架构无碍，详见 HAT 查证记录与原理图第 2 页（渲染图 [page2.png](./references/microduck-hat-20261006/page2.png)）。

## 版本历史

- **v1**（2026-10-10）：首版定稿，基于电源板空载实测 + IMU 网表 + HAT 文本提取。两处事实错误见本文开头，原文存档 [power-architecture-v1.md](./power-architecture-v1.md)。
- **v2**（2026-10-10）：评审修订。IMU 改直挂总线、电源板降为可选转接件、关闭 F1 未定项、新增「全链无保险」与「EH 座分流」两个风险项、以台架 8.4V 验证取代改焊 5V 任务。
