# 机器转写校读说明

## 原始转写与人工整理的边界

- 对本视频公开音轨进行了**本地机器转写**，不是作者字幕，也不是逐字人工听写稿。完整JSON/SRT仅在系统TEMP作为内部中间件保留；项目交付物不含完整转写，时间索引仅含原创改写的章节摘要。
- 整段约 1316.76 秒音轨均提交识别。VAD保留1272.24秒；模型生成686段，最早00:00.00、最晚21:54.91。VAD剔除与无识别区间可能包含音乐、停顿或漏识别，不能把“全片送入模型”当作“逐字全覆盖”。
- 模型及参数：`Systran/faster-whisper-small`，`faster-whisper 1.2.1`，CPU/int8，中文，beam size 5，VAD开启，`condition_on_previous_text=False`。本次成功运行耗时约264秒（包括载入与解码）。模型版本、哈希、依赖与媒体哈希见 `provenance.json`。
- 人工整理核读了按时间展开的全部ASR段落、全片每30秒概览及多个关键操作窗口的480p画面。**未逐句重新听写，也没有逐帧观看所有画面。** 笔记把明显错识规范化；TEMP中的原始JSON/SRT保留机器输出供内部追溯，不作为下载附件。
- 官方字幕接口需要登录，未获取字幕；视频画面里的硬字幕可直接在帧中读到，它们不是本地ASR的输入文字。
- 媒体只通过本视频公开播放API提供的URL下载，未读取cookies或用户凭据。模型来自公开的Systran Hugging Face仓库，模型与隔离Python环境在系统TEMP；没有尝试CUDA或安装torch。

## 使用建议

1. 用原创章节时间索引定位话题，用笔记定位可核画面；硬件型号、寄存器、针脚、命令最终对照官方资料/当前版本。
2. 低置信度字段只是模型输出指标，不是人为准确率分数；本次没有测得逐字准确率。
3. 本目录交付结构化学习笔记、原创时间索引与关键帧，不作为作者官方教程版本。
